# Deep Search and Buzz

Open **Deep Search** after selecting your results. **Get live quotes** uses 0 Buzz and itemizes the total and author fee when Civitai supplies them. Compare catalog evidence, check model-family fit, analyze examples or request a similarity ranking. The signed developer previews show live estimates.

Published execution requires AI consent and private receipt access. **Review run** prepares an exact estimate. A different total or fee requires a fresh confirmation. Civitai charges using the eligible Buzz balance and calculates its price at submission.

Find saved results in **Workspace → Deep Search history**. If a submission response was interrupted, **Find original run** checks Civitai’s history without a new charge. If another tab is confirming a run and the saved receipt is temporarily unavailable, use **Check saved run**. [Full Deep Search guide](https://chriscollins500.github.io/rasterraid/deep-search/)

**Result check** shows which expected results arrived and which still need attention. Civitai sometimes sends analysis notes together without step names. The notes remain available in the report. If a result is pending, **Check for results** reads the same run at 0 Buzz.

**Find spoken words** searches transcripts from completed runs. Load eligible transcripts or view a completed run, then enter the words you remember. Matches include any returned time and recorded source. The phrase stays in the browser.

Help with RasterRaid

Common questions

Why does my developer preview show 404?

Developer previews require the app author account on that specific Civitai domain. Sign in to the correct account on .com or .red and open the preview again.

Why don’t I see a result on both sites?

Civitai sets the catalog access and browsing level for each session. Check which account and domain are active, and open Filter & sort to review any constraints.

What should I do if a Deep Search submission was interrupted?

Open Workspace → Deep Search history and look for the receipt or workflow ID. If the outcome is unresolved, choose Find original run before trying again.

How do I find a specific file or release?

Paste its precise Civitai version link, Civitai AIR address or full SHA-256 checksum in the search field. For a local file, use Workspace → Files & setup → Identify model files.

Report a bug or suggest an improvement

Include the RasterRaid version, Civitai domain, search area, steps and what you expected to see. An example public link is helpful. GitHub issues are public, so leave private searches, account details, tokens and Buzz balances out of the report.

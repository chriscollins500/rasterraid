Search from a few words

  1. Type a model name, describe what you’re looking for, or select an example.
  2. Use Search areas to focus on models, pictures, clips, guides or another part of Civitai.
  3. Open Filter & sort for choices appropriate to that area. Search again when you’re ready.

In the developer preview, Exact title ready means you can open a matching model version while RasterRaid checks for more results.

Use Check model filters or Check media filters when a filtered search finds few results. Gallery images and Videos can check the selected base models, date range and published-prompt filter. Each suggestion includes an example and a count from its sample. The current development build can also show an example that needs two settings to change. Review the settings and choose Apply both changes. Use Back to original filters to restore the earlier search.

In the development build, try “Find SDXL LoRAs for Linocut Relief Print by @Booyaka in SafeTensor.” Search models with these filters shows the search words and catalog filters before applying them. Press Enter in the search box to search the complete text as written.

To compare the visible details in a Gallery images search, choose Match by appearance → Compare pictures. The comparison ranks up to eight loaded pictures beside the gallery. It runs on your device and uses 0 Buzz. First use can download about 231 MB. If the download fails, use a saved copy of the visual model pack from the developer release.

In the developer preview, search Videos, then use Find a scene to describe what you want to see. RasterRaid checks frames from up to six loaded clips that are at most one minute long. Play near a matched time or ask for a Deep Search quote to describe that frame. If the browser can only read the posters, RasterRaid ranks those and links to the original clips. Scene matching uses 0 Buzz and keeps your description in the browser.

In the current development build, fill in Sound in the same moment to find samples that suit both descriptions. RasterRaid checks the first 30 seconds of up to four loaded clips lasting a minute or less, then opens playback at the start of the chosen sound sample. First use can download about 273 MB of models. Both descriptions stay in the browser, and the comparison uses 0 Buzz.

Open Read English speech to transcribe the matched sound sample on your device for 0 Buzz. The first use may download about 60 MB. See review prices quotes a frame description and optional Civitai transcription of the full public clip. RasterRaid shows complete excerpts within the sample when Civitai returns timestamps. When timing is unavailable, the report labels the whole-clip transcript.

After a Videos or Audio & music search, choose More ways to explore → Find a sound by description. Describe what you want to hear in English. Add another sound to hear in the same moment or a sound to avoid. RasterRaid checks the first 30 seconds of up to four loaded public clips for 0 Buzz. The first check downloads about 42 MB. Use Play near to listen to the sampled moment.

Use Find spoken words to check English speech in the same sample. A match highlights the phrase and lets you play near the start of the excerpt. That model downloads about 59 MB. Both checks run on your device.

Choose Research this clip from a match to see Deep Search prices for that recording. For a video frame quote, move the clip to the moment you want and select Review at playback position. Choose Check recorded settings for the free video source report. Audio & music results can add sound classification to the transcript. The words you typed stay in your tab.

Try DreamShaper 8, pictures of ginger cats in a rainy window, or guides for ComfyUI workflows.

Search from a picture or clip

Choose Add a picture or paste a public Civitai media link. In the visual comparison, focus on the whole picture or a selected detail. Choose the palette, lighting, layout or texture you want to match or avoid. Eligible clip results open close to the matched moment.

In the 0.0.11 developer prerelease, Find the same subject → Compare on this device compares up to six eligible public previews. Combine up to four references and choose which subjects to match or avoid. The first comparison downloads about 78–81 MB of model files. It uses 0 Buzz, and pictures from your device stay in your browser.

Follow an exact link

Paste a Civitai model, picture, clip, post, article or collection link. An exact model version gives you its own examples and file details. A Civitai model download link can identify an exact version or file in the catalog. Check recorded settings shows the references Civitai recorded for a picture or clip. Two media links can open a side-by-side settings comparison.

Compare, refine and report

Choose Compare on up to three model releases, then Compare free. See their base-model families, published file details and sample pictures together. Build a free report combines selected sources, such as model releases, media and articles, and links to the evidence. Choose Copy report for a Markdown version.

In the 0.0.11 developer prerelease, choose Models with Gallery images or Videos in a free report to check the model versions recorded in the samples. When several posts name the same version in their media metadata, Verified connections links one example from each post.

In the current development build, choose Research report → Explore a model release with Gallery images. When two pictures record the exact release and share enough reported settings, Pictures to compare shows the matching fields and the recorded differences. Choose Compare recorded settings for the full free report and eligible Deep Search estimates. The suggestion uses the pictures from the first gallery page.

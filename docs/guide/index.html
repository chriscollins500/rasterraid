Opening the preview

RasterRaid runs inside Civitai. Developer previews are available to the app author. Sign in on the same domain as the preview you open.

Search from a few words

  1. Type a model name, describe what you’re looking for, or select an example.
  2. Use Search areas to focus on models, pictures, clips, guides or another part of Civitai.
  3. Open Filter & sort for choices appropriate to that area. Search again when you’re ready.

In the developer preview, Exact title ready means you can open a matching model version while RasterRaid checks for more results.

In the 0.0.10 developer prerelease, Check model filters or Check media filters can help when a filtered search finds few results. Gallery images and Videos can check the selected base models, date range and published-prompt filter. Each suggestion includes an example and a count from its sample. Choose a change to search again, or use Back to original filters.

To compare the visible details in a Gallery images search, choose Match by appearance → Compare pictures. The comparison ranks up to eight loaded pictures beside the gallery. It runs on your device and uses 0 Buzz. First use can download about 231 MB. If the download fails, use a saved copy of the visual model pack from the developer release.

In the developer preview, search Videos, then use Find a scene to describe what you want to see. RasterRaid checks frames from up to six loaded clips that are at most one minute long. Play near a matched time or ask for a Deep Search quote to describe that frame. If the browser can only read the posters, RasterRaid ranks those and links to the original clips. Scene matching uses 0 Buzz and keeps your description in the browser.

In the 0.0.10 developer prerelease, use More ways to explore → Find spoken words after a Videos or Audio & music search. Enter a phrase to check the first 30 seconds of up to four loaded public clips for English speech. A match highlights the words and lets you play near the start of the excerpt. The model download is about 59 MB. The check runs on your device and uses 0 Buzz.

Choose Research this clip from a match to see Deep Search prices for that recording. For a video frame quote, move the clip to the moment you want and select Review at playback position. Choose Check recorded settings for the free video source report. Audio & music results can add sound classification to the transcript. The words you typed stay in your tab.

Try DreamShaper 8, pictures of ginger cats in a rainy window, or guides for ComfyUI workflows.

Search from a picture or clip

Choose Add a picture or paste a public Civitai media link. In the visual comparison, focus on the whole picture or a selected detail. Choose the palette, lighting, layout or texture you want to match or avoid. Eligible clip results open close to the matched moment.

In the 0.0.10 developer prerelease, Find the same subject → Compare on this device compares up to six eligible public previews. Combine up to four references and choose which subjects to match or avoid. The first comparison downloads about 78–81 MB of model files. It uses 0 Buzz, and pictures from your device stay in your browser.

Follow an exact link

Paste a Civitai model, picture, clip, post, article or collection link. An exact model version gives you its own examples and file details. A Civitai model download link can identify an exact version or file in the catalog. Check recorded settings shows the references Civitai recorded for a picture or clip. Two media links can open a side-by-side settings comparison.

Compare, refine and report

Choose Compare on up to three model releases, then Compare free. See their base-model families, published file details and sample pictures together. Build a free report combines selected sources, such as model releases, media and articles, and links to the evidence. Choose Copy report for a Markdown version.

In the 0.0.10 developer prerelease, choose Models with Gallery images or Videos in a free report to check the model versions recorded in the samples. When several posts name the same version in their media metadata, Verified connections links one example from each post.

This documentation site

These pages are hosted by GitHub Pages. The site renders documentation and filters the coverage list in your browser. GitHub handles requests to the site and any issues you choose to open. GitHub’s privacy statement.

Searches and Civitai access

Search terms, allowed filters and exact IDs are sent to Civitai to resolve results. Civitai provides the account, browsing permissions and content previews. The public filter feed supplies Civitai filter names. The app can request AI access for quotes or runs, and it requests private collection access separately when you ask to include those collections.

Files you choose

Local pictures, workflow graphs and model files are read in your browser. A catalog check may send extracted Civitai IDs, model filenames or checksums. Deep Search quotes identify the public evidence selected for that analysis. Local visual references can guide a match on your device. Spoken-word searches run in your tab. A clip research quote uses the selected public clip and, for a frame review, its selected time.

Saved workspace and receipts

When enabled for the published app, Civitai’s private document store holds the viewer’s saved searches, picks, settings and run records. Preview workspace changes can be kept in the current session. Report and backup downloads are files you control. Clear recent searches or preferences in Workspace and use Account settings → Security & Apps → App storage on Civitai to manage production app data.

In version 0.0.12, Workspace → Settings → Private storage shows the usage and limits Civitai reports for your account. If a save exceeds the per-item limit, remove saved items or import a smaller selection. This version keeps the private collection closed to other apps. You can download workspace backups and reports.

The development build keeps up to 32 recent edit receipts with the private workspace document so it can recover interruptions. Workspace backup files contain saved searches and picks.

Build and verify RasterRaid

Run the app locally

Use Node.js 24 or newer. The native app uses static browser modules and has no runtime npm packages. From the repository root, build the app, run its tests and start the local example.

npm run build
npm test
npm run verify:bundle
npm run dev -- 5188 dist --mock-deep-search

Open http://127.0.0.1:5188/mock-deep-search and try the Linocut walkthrough. Simulated credits use 0 Buzz. See the repository README for Civitai’s app validation commands and releases for hosted status.

Build the documentation

Run node site/build.mjs at the repository root to regenerate docs/. Use node site/build.mjs --check to compare the committed pages and assets to their source. GitHub Pages serves the generated folder.

Repository checks

GitHub CI runs the app tests, verifies the browser bundle and checks the generated documentation. CodeQL scans the native code. Dependabot monitors npm and GitHub Actions. Consult the repository’s Actions and Security pages for the current results.

Search, compare and build reports for free. Open Deep Search on a result to price additional work. The available comparisons depend on the selected evidence.

What can a closer look check?

Compare the picks
Compare exact releases using descriptions and catalog details.
Check compatibility
Check which picks fit the family and requirements you selected.
Compare the pictures
Check catalog fit and analyze the exact example pictures.
Find the closest look
Compare the resemblance of selected previews and keep the catalog sources alongside the ranking.

Eligible reports can also quote a transcript, a music description, a sampled video frame or a synthesis of completed research.

Read a live estimate

  1. Pick your results and choose Get live quotes. Civitai may ask you to grant AI access for pricing.
  2. Review the total in Buzz and any itemized app author fee. Pricing uses 0 Buzz.
  3. When paid execution is available, Review run opens the exact estimate. Confirm to start. If the total or fee changes before submission, review the new estimate and confirm again.
Verified Linocut example

The developer previews returned 3, 6, 6 and 7 Buzz for the four options above. Each included a 0 Buzz author fee in the author session. Civitai quotes your picks using your own session and eligible balance.

Civitai chooses the eligible Blue, Green or Yellow Buzz balance and applies its current author-fee rules. A workflow can be repriced when a later step receives its input. Published execution saves a private Civitai receipt before a run starts.

Recover a result or receipt

Open Workspace → Deep Search history to find a RasterRaid run by status or workflow ID. Copy receipt keeps the available estimate, fee and reported cost. If a reply was interrupted, use Find original run first. Choose Continue looking if there are more entries to check. The lookup uses 0 Buzz. A separately confirmed retry uses the original operation ID.

If another tab is confirming a run, RasterRaid loads its saved receipt when it detects the change. Use Check saved run to refresh the receipt if storage was temporarily unavailable. Checking the saved run uses 0 Buzz.

Result check compares received results with the approved request and shows missing results and notes Civitai returned together. Use Check for results in history to read the original run again at 0 Buzz.

Find spoken words searches completed transcripts available in the open workspace. Load eligible transcripts or view a completed run, then enter a phrase. Each match shows the excerpt, any returned time, and its recorded source when available. Search words stay in the browser.

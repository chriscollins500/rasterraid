Save a search or shortlist

Open Workspace, enter a name and choose Save current search or Save model picks. Reopening a shortlist checks access again and keeps eligible exact version and file identities. Recent public searches can also be reopened in the current tab.

In the 0.0.10 developer prerelease, signed-in viewers can choose Find my public work to see recent pictures, clips, audio and verified posts. Enter a topic to filter this sample by published titles, descriptions or tags. Open your Civitai profile to browse older uploads.

Check models and workflows from your setup

Under Files & setup, choose an existing ComfyUI workflow or select model files to verify their full SHA-256 checksums. RasterRaid can read supported CiviScribe sidecars and Civitai Metadata Studio exports. Matches link to the exact Civitai version or file. Several listings can share a checksum, so RasterRaid shows the matches for you to review.

From an eligible public picture or clip, choose Check recorded settings → Compare with my setup to compare its recorded references with your local profile.

Keep or compare a report

Save a free report for comparison with a fresh search. Reopen ordinary saved catalog searches to see changes in the checked results. For a completed Deep Search run, Save report file keeps the captured notes, sources and available prices. Open it from Deep Search history in its original Civitai account and site.

Back up, restore or personalize

Use Back up and restore to export, import or selectively merge saved searches and shortlists. In Settings, opt into preferences for model and media ranking or restore standard ranking. The search menu lets you reorder or hide shortcuts.

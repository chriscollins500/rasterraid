# Contributing to RasterRaid

Start from a public Civitai example or a synthetic fixture. Record the expected source links, exact version IDs, and the visible result when they matter to the change. Check both hostnames when modifying a route or browsing permission boundary.

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run verify:bundle
node site/build.mjs --check
```

Edit the documentation in `site/`, run `node site/build.mjs` and include the changed `docs/` files. The project website and Wiki cover user workflows. [Development guide](https://chriscollins500.github.io/rasterraid/development/) · [GitHub Wiki](https://github.com/chriscollins500/rasterraid/wiki)

Use the loopback simulation for workflow confirmation and recovery. A live quote uses 0 Buzz. Keep credentials, signed URLs and personal run records outside commits and public reports. [Security reporting](SECURITY.md)

# Reporting a vulnerability

Use GitHub’s private vulnerability reporting to share a potential issue in RasterRaid. Include the affected version or commit, which Civitai domain was involved, and a reproducible example using public or synthetic inputs. Keep any account credentials and private catalog data in your own environment. [Report a vulnerability](https://github.com/chriscollins500/rasterraid/security/advisories/new)

Report ordinary product bugs and documentation issues in the public tracker. [GitHub issue forms](https://github.com/chriscollins500/rasterraid/issues/new/choose)
